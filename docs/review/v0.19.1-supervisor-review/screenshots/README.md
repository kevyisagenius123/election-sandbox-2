1. `01-editorial-home.png`: public-facing editorial introduction.
2. `02-national-consequence-and-route.png`: national scenario, Electoral College consequence, and selected route.
3. `03-pennsylvania-3d-laboratory.png`: Pennsylvania state laboratory and 3D local terrain.
4. `04-pennsylvania-contributors.png`: geographic contribution ranking for a flipped Pennsylvania scenario.
5. `05-michigan-3d-laboratory.png`: Michigan detailed state laboratory.
6. `06-michigan-evidence-ledger.png`: Michigan source, geometry, coverage, treatment, and denominator evidence.

These are review evidence, not pixel-perfect marketing exports.
