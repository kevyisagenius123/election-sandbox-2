# 0021. Private-alpha hardening before geographic expansion

**Status:** Accepted

**Release:** v0.18

**Date:** 2026-08-12

## Decision

Pennsylvania and Michigan must demonstrate bounded runtime ownership, deterministic replay, responsive hierarchy, and explicit data-shipping records before a third detailed state enters the product. v0.18 therefore adds evidence and release gates without changing election-model semantics.

The browser exposes a development-only, immutable `window.__sandboxDiagnostics()` snapshot. It contains resource counts, declared artifact and geometry bytes, pending work, map ownership, and active layer identifiers. It exposes no scenario foundation, setter, store, or mutation method.

The canonical stress journey repeatedly opens real Michigan and Pennsylvania precinct shards, switches ownership, forces controlled Chromium garbage collection, and verifies the same national totals, route consequence, and recipe fingerprints on every cycle. Five warm-up cycles precede thirty measured cycles. A separate hostile journey delays geometry responses and replaces active-state ownership before they complete.

Visual acceptance covers 800×900, 1024×768, 1180×820, 1280×800, 1350×900, and 390×844. Strict full-page comparisons mask the WebGL surface, whose GPU antialiasing is not a stable DOM contract. Semantic assertions separately verify the active Michigan county layer, Electoral College score, route status, route ledger, and contribution flow. Reduced-motion mode removes route-progress animation completely.

## Consequences

- The runtime profile has written heap, slope, latency, cache, worker, animation, and WebGL pass/fail budgets.
- A map-column alignment rule prevents the right-hand editor from stretching the map stage at medium widths.
- Production manifests declare compact model-shard byte sizes, and geometry diagnostics sum audited shard sizes instead of pretending to observe GPU allocation.
- A detailed-state admission checklist and one exception record per state are required before registration.
- Redistribution review remains a delivery gate; provenance alone is not treated as redistribution permission.
- No third detailed state is admitted in this release.

## Next step

Run a small task-based private alpha, triage comprehension failures and defects, and clear the intended data-distribution path. State #3 remains blocked until those findings and gates are resolved.
