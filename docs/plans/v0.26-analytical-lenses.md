# v0.26 Plan: Election Night Analytical Lenses

Date: 2026-08-23

## Objective

Turn the accepted current-prefix analytics into interactive visual explanations without adding a second map engine, hidden future information, or the old Sandbox's collection of continuously active WebGL canvases.

The user-facing question is:

> How did the reported count move, when did it move, and which visible returns produced that movement?

## Renderer law

- deck.gl remains the only geographic map renderer.
- Regular ECharts may render bounded two-dimensional analytical lenses.
- Every chart is lazy, visible-tab-only, and fully disposed when closed.
- Chart datasets are produced by the replay worker and contain only the visible event prefix.
- ECharts GL is not admitted by default. It requires a separate evidence and performance comparison against a two-dimensional equivalent.

## Sequence

### v0.26A: Reported margin timeline (implemented)

- Build a deterministic current-prefix margin timeline for the three-state replay.
- Preserve national, PA, MI, and WI reported margins at each admitted display point.
- Cap the visible dataset at 320 points while preserving the latest return and lead changes.
- Seek the existing replay and deck.gl map by clicking the chart.
- Subscribe to timeline payloads only while the lens is open.
- Mount one canvas and dispose it when the tab closes.
- Verify desktop and mobile layouts.

### v0.26B: Reporting velocity and state comparison (next)

- Add ballots-per-logical-minute and returns-per-logical-minute views.
- Compare PA, MI, and WI activation, pace, stalls, and progress without combining those measures into a synthetic score.
- Reuse the same visible-tab subscription and lifecycle contract.
- Link chart scope to the existing state and county selection where the evidence supports it.

### v0.26C: ECharts GL research gate

- Prototype one count-landscape view with time, geography, and published-ballot volume.
- Compare it against a two-dimensional heatmap using comprehension, bundle, GPU, memory, and interaction evidence.
- Reject the GL view if the third dimension does not improve understanding materially.
- Never use ECharts GL as a second geographic map engine.

## Explicit non-goals

v0.26 does not add:

- win probability;
- expected candidate share for unreported ballots;
- projection or race-call logic;
- hidden future returns;
- demographic causality;
- a replacement for the shared deck.gl map;
- multiple continuously mounted chart canvases;
- backend, memberships, rooms, or video export.

## Current boundary

v0.26A is complete. Proceed with v0.26B only after supervisor review of the margin timeline and its runtime footprint. ECharts GL remains deferred to v0.26C and must not enter the next implementation slice.
