# v0.25A: Headless analytics contract

## Summary

v0.25A creates the evidence boundary for Sandbox 2.0 analytics. It turns already-trusted election, scenario, contribution, Electoral College, and current replay-prefix values into typed, deterministic analytic envelopes.

This is an engineering release. It does not redesign the visible laboratory.

## What changed

- A separate `packages/election-analytics` package now owns analytic definitions, envelopes, builders, validation, canonical serialization, and fingerprints.
- Twenty initial definitions cover certified endpoints, scenario endpoints and operations, geographic contributions, Electoral College consequences, current-prefix reported totals, and explicit progress ratios.
- Every envelope identifies its semantic class, integer unit, candidate scope, geography, time scope, sources, transform version, availability, and caveat.
- Missing denominators produce unavailable analytics rather than zero or an invented fallback.
- Return and represented-ballot progress retain their exact numerator and denominator.
- Current-prefix builders consume only replay observations available at the selected cursor.
- Residual contributions remain outside mapped geography instead of being assigned a false polygon.

## Preserved guarantees

- Pennsylvania, Michigan, and Wisconsin certified and scenario endpoints still reconcile exactly.
- Existing scenario arithmetic, replay scheduling, URLs, React behavior, deck.gl rendering, and election-night controls are unchanged.
- No probability, projection, Decision Desk call, demographic behavioral estimate, backend, or new page was added.

## Verification

The package has dedicated contract tests for registry law, exact reconciliation, requested versus realized operations, signed contributions, current-prefix isolation, missing-versus-zero behavior, ratio operands, deterministic fingerprints, tamper rejection, and headless implementation.
