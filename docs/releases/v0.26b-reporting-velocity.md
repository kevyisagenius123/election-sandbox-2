# v0.26B: Reporting velocity and state comparison

Date: 2026-08-23

v0.26B turns the Election Night Timeline tab into a compact analytical workspace with three internal lenses:

- **Margin:** the accepted national and three-state reported-margin timeline.
- **Velocity:** ballots or returns published per logical minute in a trailing 15-minute window.
- **Compare states:** separate PA, MI, and WI activation, latest activity, stall status, ballot progress, unit progress, and current pace.

The velocity chart seeks the same replay worker and persistent deck.gl map. Selecting a state comparison card focuses that state on the map. Ballot and unit progress remain separate because local reporting units differ greatly in size.

## Runtime boundary

- The worker owns the candidate-blind pace index and current-prefix derivation.
- Only the visible return prefix is serialized.
- Output is capped at 320 deterministic points while retaining the latest point and state/national ballot and return-rate peaks.
- The Timeline workspace uses one shared visibility subscription.
- Margin and Velocity mount one regular ECharts canvas at a time and dispose it when switched or closed.
- Compare states mounts no canvas.
- ECharts GL remains uninstalled.

## Evidence boundary

Velocity describes published activity. It is not a prediction of future reporting speed, a competitiveness score, a race-call signal, or a probability. Modeled endpoint denominators are used only to calculate transparent ballot and reporting-unit progress.
