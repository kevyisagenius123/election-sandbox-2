# v0.25C: Replay descriptive analytics

## Summary

v0.25C creates the headless explanation layer for the count already visible on Election Night. It derives current-only diagnostics from canonical local returns and the matching reducer prefix without reading the final scenario endpoint or any future event.

## What changed

- Five-, fifteen-, and thirty-minute logical windows report exact return, ballot, and Harris-minus-Trump movement.
- Exact integer rates express returns per hour and ballots per minute.
- Return-unit progress and represented-ballot progress remain separate, denominator-backed measures.
- The newest return retains its state, county, reporting-unit, timestamp, candidate vector, and signed margin movement.
- Deterministic rankings identify the largest current county and unit margins plus the largest recent movers.
- Mathematical openness states whether the current reported margin can still be overtaken by all explicitly modeled outstanding ballots. It is not a forecast or call.
- Chronology diagnostics distinguish not open, awaiting first return, counting, complete, and user-threshold stalls.
- Prefix validation now reconciles national, state, mapped, off-map, county, and reporting-unit reducer state before producing analytics.
- Canonical serialization, a frozen fixture fingerprint, and fail-closed deserialization make the output reproducible and tamper-evident.

## Preserved guarantees

- The complete replay stream and hidden endpoint candidate totals are structurally absent from the input contract.
- Missing progress denominators remain unavailable.
- No wall clock, random source, probability, projection, race call, React, deck.gl, map, backend, or visible interface changed.
- Existing scenario, replay, reducer, worker, and v0.25B fingerprints remain intact.
