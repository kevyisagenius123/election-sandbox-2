# v0.27A: Scenario explanation hierarchy

Date: 2026-08-23

v0.27A turns the existing Swingometer arithmetic into one readable explanation. The Contributors drawer now connects:

1. the operation responsible for the most movement;
2. the county and mapped local unit contributing most in that direction;
3. whether the state changed winner and how many electoral votes changed hands.

For the canonical Pennsylvania review scenario, the product now explains that preference is the main driver, Allegheny County is the strongest county contribution, and Pennsylvania flips from Trump to Harris with 19 EV changing hands.

## Architecture

- `scenarioExplanation.ts` is a headless deterministic selector built on the accepted scenario delta ledger.
- The selector preserves operation sign, residual honesty, mapped-unit boundaries, exact state winners, and exact EV allocation.
- React formats the contract as a compact three-column causal chain on desktop and one column on mobile.
- The existing waterfall and ranked county/reporting-unit ledger remain the detailed proof underneath.

## Product boundary

This release does not add demographic causality, third-party plurality geography, probability, projections, calls, or a second chart. Geographic third-party allocation is the next bounded slice.
