# v0.26C: ECharts GL research gate

Date: 2026-08-23

v0.26C completes the planned analytical-lens program with an evidence-backed renderer decision. It builds two isolated views of exactly the same detailed PA, MI, and WI election-night data:

- a regular ECharts 2D return pulse matrix;
- an ECharts GL three-dimensional count landscape.

The research fixture contains 20,499 detailed returns, 16,145,836 ballots, 48 fixed replay-time bins, three state rows, and 144 marks. Every mark preserves exact Harris, Trump, other, ballot, and return totals. Prefix tests prove that future return identities and candidate changes cannot leak into an observed dataset.

## Outcome

ECharts GL is not admitted to production. The 3D view adds perspective and occlusion without adding a new variable, owns two canvases for one chart, initializes more slowly, and adds a large isolated research chunk. deck.gl remains the sole WebGL and geographic renderer.

The 2D return pulse matrix survives the comparison as the clearer analytical concept. It is retained in the research harness for future consideration, but it is not inserted into the production dock in this release.

## Isolation

- `research/v0.26c/` is a standalone Vite harness with its own build and Playwright checks.
- `echarts-gl` is a development dependency only.
- `src/` contains no ECharts GL import.
- The production Vite inputs remain `/index.html` and `/app/index.html` only.
- The production bundle remains unchanged apart from source-test and documentation additions.
