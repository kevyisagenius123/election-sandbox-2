# v0.26A: Reported margin timeline

## Summary

v0.26A adds the first interactive Election Night analytical lens. A regular ECharts line chart shows how the reported national, Pennsylvania, Michigan, and Wisconsin margins moved across logical replay time and seeks the same replay and deck.gl map when clicked.

## What changed

- A new Timeline tab lives in the existing Election Night bottom dock.
- National, PA, MI, and WI series use only published local returns.
- The line covers the complete replay-time axis while stopping at the current visible prefix.
- The vertical playhead follows the current replay time.
- State selection keeps the national line visible and emphasizes the selected state.
- A visible-prefix readout reports exact return counts and current state margins.
- The timeline dataset is deterministically capped at 320 points while retaining the latest return and lead changes.
- Chart clicks seek the existing replay worker, which updates the same 3D map and state desk.
- The browser subscribes to timeline payloads only while the Timeline tab is open.
- ECharts is dynamically imported into an isolated chunk. The chart owns one canvas and disposes it when the user leaves the tab.
- Mobile Timeline selection expands the dock so the chart has a usable analytical workspace.

## Preserved guarantees

- deck.gl remains the only map renderer.
- ECharts GL is not installed or loaded.
- No hidden future return, endpoint candidate share, probability, projection, or race call enters the chart.
- Replay votes, candidate-blind chronology, Swingometer endpoints, and existing analytic contracts remain unchanged.
- Unsupported jurisdictions remain absent from Election Night.
